Criterio General Para Un RAG Tecnico De Este Tipo

Un chatbot tecnico robusto no deberia depender solo de PDFs normativos. Lo normal es organizar el corpus por capas:

  1. Normativa oficial: BOE, reales decretos, reglamentos e ITCs.
  2. Guias oficiales: MINCOTUR, IDAE, CTE, RIPCI.
  3. Manuales practicos: fabricantes, mantenimiento, ejemplos y casos reales.
  4. Documentacion interna: procedimientos, checklists, manuales propios de Regenera.
  5. Datos estructurados: tablas, FAQs, preguntas de examen, periodicidades y relaciones campo-valor.

Para Azure AI Search, el enfoque mas adecuado es busqueda hibrida: texto exacto + vector + reranking semantico. Esto es especialmente importante para preguntas como tabla 3.1, ITC-BT-52, TN-S, conductor de proteccion o limpieza de evaporadores, donde la literalidad importa tanto como la similitud semantica.

Decision Final

El corpus actual es valido como primera base, pero el siguiente paso no deberia ser meter todos los PDFs nuevos. El camino mas seguro es:

  1. Arreglar RITE con documentos pequeños, limpios y directos.
  2. Mejorar grupos electrogenos con HIMOINSA.
  3. Completar alta tension antes de retirar el documento actual.
  4. Reindexar y validar con las preguntas que ya fallaron.
  5. Despues enriquecer REBT y FV por fases.
